# Flirt_Baazaar

## Project Overview

Flirt_Baazaar is a highly advanced PHP-based phishing simulation platform developed to mimic real-world social engineering and phishing attack techniques with the same level of sophistication found in Infinite_BET. It is intentionally created to educate and raise awareness among cybersecurity professionals and end-users about phishing threats through a realistic, multi-vector data capture approach.

---

## Objectives

- Replicate complex phishing attack dynamics focusing on social engineering vectors.
- Simulate multi-dimensional data collection: biometric, behavioral, and metadata.
- Provide a strong educational tool for training and defense strategy development.
- Equip cybersecurity teams with a controlled platform to understand attacker capabilities.

---

## Features

- **Full Spectrum Data Collection:**
  - Real-time IP and geolocation tracking.
  - Browser, OS, and hardware fingerprinting.
  - Continuous webcam snapshots and video captures saved securely.
  - Clipboard content logging.
  - Detailed interaction and session metadata logging.
  
- **User Behavior Analysis:**
  - Automated capture of clicks, inputs, and session timing.
  - Contextual logging enabling forensic and behavioral analytics.

- **Robust Backend Logic:**
  - PHP-driven server-side processing for secure data handling.
  - Organized file system storage for media and logs.
  - Scalable architecture for potential bulk victim simulations.

- **User-Focused Interface:**
  - Designed to convincingly imitate popular social/dating platforms.
  - Employs advanced UI/UX tricks for authenticity and engagement.

---

## Architecture

- Frontend powered by HTML and JavaScript that integrate media capture APIs seamlessly.
- PHP backend handles authentication, logging, and data persistence.
- Data securely stored on the server within clearly organized directories for audit and review.
- Incorporates best practices for secure server-side scripting to minimize exposure.

---

## Ethical Use and Compliance

This tool is expressly designed for legal, ethical use in cybersecurity training, red/blue team exercises, and awareness campaigns. Any malicious use is strictly prohibited and against the intended purpose.

---

## Deployment

- Requires a PHP and MySQL-enabled server environment.
- HTTPS is essential to enable browser-level permissions for media capture.
- Ideal for internal security training labs or as proof-of-concept for phishing risk presentations.

---

## Impact and Contributions

Flirt_Baazaar stands as a milestone in phishing simulation projects by blending biometric data capture with rich behavioral analytics to simulate realistic and complex attack surfaces.
